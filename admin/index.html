Come creo la chiave di accesso?
  1. Su GitHub, entra con l'account cristinadalessandro.
  2. Foto profilo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nome: "Area riservata sito". Scadenza: la più lunga disponibile.
  4. Repository access: Only select repositories → cristinadalessandro.github.io.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Tocca Generate token, copia la chiave e incollala qui sopra. Non darla a nessuno.
